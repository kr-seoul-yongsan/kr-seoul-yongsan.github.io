# 용산구 · 서울특별시

> 용산구 지역 정보 랜딩 사이트

## 🌐 랜딩 페이지

### **https://kr-seoul-yongsan.github.io/**

용산구는 서울 한강 이북 중앙에 놓인 자치구로, 남산의 녹지와 한강의 수변을 남북 양끝에 두고 있다. 이태원 관광특구의 이국적인 거리와 한남동 고급 주거지, 그리고 반환 미군기지 위에 조성 중인 용산공원이 한 구역 안에 공존한다. 국립중앙박물관과 전쟁기념관 같은 대형 문화시설이 몰려 있어 서울에서 손꼽히는 문화·전시 밀집지로 통한다. 용산역과 서울역이라는 두 철도 관문을 끼고 있어 유동 인구와 방문객이 끊이지 않는 곳이기도 하다. 오래된 전자상가와 새로 들어서는 국제업무지구가 맞물리며 도심 경관이 빠르게 재편되고 있는 자치구다.
